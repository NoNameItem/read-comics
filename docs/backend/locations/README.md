# Locations

Stores both geographic and fictional locations across the shared universe, including search helpers.

## Key modules
- `models.py` contains location data and links to teams, story arcs, and other entities.
- `search_adapters.py` and `api/` handle search indexing and REST access.
- `sublist_querysets.py` and `tasks.py` provide curated querysets and background updates.
- `templates/` and `views.py` deliver location directory pages and detail screens.
