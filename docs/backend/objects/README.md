# Objects

Documents items and artifacts appearing in comics.

## Key modules
- `models.py` tracks object metadata, ownership, and properties.
- `search_adapters.py` and `api/` expose search integrations and serialization layers.
- `sublist_querysets.py` and `tasks.py` provide helper querysets and synchronization jobs.
- `templates/` and `views.py` offer search interfaces and object detail cards.
