# Concepts

Manages metadata, concepts, and visual reference guides that connect comic data.

## Key modules
- `models.py` and `sublist_querysets.py` define concept entries and helper querysets for listings.
- `search_adapters.py` and `api/` provide search integration and filtering endpoints.
- `tasks.py` powers periodic updates and flag synchronization.
- `templates/` and `views.py` deliver concept detail pages.
