# People

Captures data about creators, artists, and industry contributors.

## Key modules
- `models.py` models authors, artists, and related personas.
- `search_adapters.py`, `api/`, and `tasks.py` support indexing, REST endpoints, and updates from external sources.
- `sublist_querysets.py` builds helper querysets for related person lists.
- `templates/` and `views.py` render biography cards and reference pages for contributors.
