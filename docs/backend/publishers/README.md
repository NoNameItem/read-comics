# Publishers

Manages publisher data, branding assets, and histories.

## Key modules
- `models.py` defines publishers and related branding metadata.
- `search_adapters.py`, `api/`, and `views.py` expose search-driven lists and API responses.
- `sublist_querysets.py` and `tasks.py` support helper querysets and synchronization with external data.
- `templates/` render publisher profiles and related collections.
