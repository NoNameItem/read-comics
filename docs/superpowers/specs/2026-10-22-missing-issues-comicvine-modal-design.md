# Модалка с данными ComicVine на странице пропущенных выпусков — дизайн

Дата: 2026-10-22. Статус: черновик на согласование. Задача: `read_comics-29u`.

**Границы ответственности.** Макетов нет, поэтому спека — источник истины и по вёрстке, и по
поведению, данным и крайним случаям. Вёрстка намеренно минимальная (см. «Ограничения»).

## Что делает

На странице пропущенных выпусков у строки издателя, тома и выпуска появляется кнопка, которая
открывает полноэкранную модалку с данными этого объекта из нашей Mongo (коллекции `comicvine_*`,
которые наполняет паук через API ComicVine). Модалка — запасной способ посмотреть то, что обычно
смотрят на сайте ComicVine, пока сайт недоступен.

## Макеты

Макетов в Claude Design нет. Вёрстка задаётся текстом этой спеки. Во время брейншторма показывался
черновой набросок в браузере (visual companion) — он был только опорой для обсуждения, в репозиторий
не копируется и источником истины не является: всё, что из него решено, перенесено в текст ниже.

## Зачем

Сайт ComicVine периодически недоступен (2026-10-22 — отдаёт 500), при этом API работает. Разбор
пропущенных выпусков опирается на сайт: по ссылке из строки таблицы пользователь смотрит издателя,
том или выпуск и решает, что делать со строкой. Пока сайт лежит, работа стоит.

Всё, что для этого нужно, уже лежит в Mongo. Картинки (обложки) хранятся только как ссылки на
`comicvine.gamespot.com/a/uploads/...`, но во время сбоя сайта они открываются (проверено
пользователем 2026-10-22), поэтому показываем их по сохранённым ссылкам.

Как пользователь смотрит на каждый уровень (его слова, пересказ):

- **Издатель:** короткое и полное описание — чтобы отсеять неанглоязычных издателей и тех, кто не
  выпускал ничего интересного.
- **Том** (открывается чаще всего): год, описания — проверить, что том не дублирует уже скачанную
  серию в другом формате (TPB, переиздание); алиасы — искать том под другим именем; обложки
  выпусков тома — визуально убедиться, что это нужный выпуск, а не другой с тем же названием.
- **Выпуск:** описание (может оказаться, что это сборник уже найденных выпусков), основная обложка
  и её варианты.

## Цели

1. С каждого уровня таблицы (издатель, том, выпуск) открывается модалка с данными из Mongo, которых
   достаточно для решения по строке без сайта ComicVine.
2. Попутно исправить баг кнопки «Ignore» издателя на страницах по категориям и пропущенную запятую в
   списке полей паука выпусков (см. «Попутные баги»).

## Не цели

- **Не заменяем сайт ComicVine.** Основным способом смотреть данные остаётся сайт; ссылки в таблице
  не меняются (решение пользователя).
- **Не украшаем вёрстку.** Страница будет переписана в миграции на DRF + Nuxt 4 (`read_comics-7uh`),
  поэтому вкладываться в текущий Django-шаблон не нужно (решение пользователя).
- **Список томов издателя не показываем** — он и так виден в таблице (решение пользователя).
- **Сюжетные арки выпуска не показываем** — «это лишнее» (решение пользователя).
- **Пропущенные выпуски в сетке обложек тома не подсвечиваем** — это лишний запрос и смешение Mongo с
  Postgres ради пользы, которая прямо не нужна (решение пользователя). Эндпоинт читает только Mongo.
- **Картинки не кэшируем у себя** — показываем по ссылкам ComicVine (они работают во время сбоев сайта).
- Не делаем API для будущего Nuxt-фронта: эндпоинт отдаёт HTML-фрагмент для текущей страницы.

## Анти-цели

- Модалка, которая тормозит страницу: на томах в сотни выпусков (в нашей базе у Detective Comics
  1937 — 883, у Action Comics 1938 — 864) все обложки не должны грузиться разом.
- Кнопка, которая перестаёт работать после Skip/Ignore: таблица после этих действий
  перерисовывается по AJAX.
- Ссылки внутри модалки, ведущие на тот же лежащий сайт ComicVine (кроме явной кнопки «Open on
  ComicVine» в подвале).

## Ограничения

- Фронт страницы: Bootstrap 4.3.1 (тема Frest), jQuery 3.3.1, Font Awesome (`fad`). Новых библиотек не
  подключаем.
- Доступ к Mongo — как в остальном коде: `MongoClient(settings.MONGO_URL).get_default_database()`,
  pymongo 3.11.3 (`requirements/base.txt`).
- Все вьюхи приложения закрыты `IsAdminMixin` (staff или superuser) — новая тоже.
- Шаблон таблицы `issues_table.html` общий для трёх видов страницы: все пропущенные, «watched» и
  страницы по категориям (`<category>/<slug>/`).

## Где открывается

- В строке издателя, тома и выпуска (`issues_table.html`) рядом с существующей ссылкой на ComicVine
  — кнопка с иконкой; по клику открывается модалка соответствующего уровня. Точное место и иконка —
  на усмотрение реализации, но кнопка одинаковая на всех трёх уровнях. *(моё решение)*
- Кнопка не выводится, если у строки нет id объекта этого уровня. Так бывает у строк, для которых
  паук ещё не скачал том или издателя (пустые `volume_*` / `publisher_*`, см. `read_comics-1mk`), и у
  томов, у которых в ComicVine нет издателя (`publisher: null`).
- Работает на всех трёх видах страницы: адрес эндпоинта не зависит от вида страницы.

## Экраны

Общее для всех трёх модалок:

- **Модалка на весь экран** (решение пользователя): `modal-dialog modal-dialog-scrollable modal-full`,
  как у существующей модалки «Reload from DO» на этой же странице.
- **Тексты интерфейса — по-английски**, как вся остальная страница (Skip, Ignore, Close, Reload from DO;
  в проекте `USE_I18N = False`). Ниже тексты даны по-английски. *(моё решение)*
- **Шапка:** название объекта. **Подвал:** дата, на которую данные скачаны в нашу базу
  (`crawl_date`, «Data as of 2026-10-05»), кнопка «Open on ComicVine» (`site_detail_url`, в новой
  вкладке) и «Close». Дата нужна, потому что наша копия может отставать от ComicVine (см. «Замеры»).
  *(моё решение)*
- **Пустые и недокачанные поля** не прячутся: подпись поля остаётся, а вместо значения — одно из двух
  приглушённым текстом *(моё решение)*:
  - ключ в документе есть, значение пустое (`null`, `""`, `[]`) — «none»: в нашей копии поле пустое;
  - ключа в документе нет — «not downloaded yet»: ни один запрос, записавший документ, это поле не
    запрашивал (ComicVine возвращает каждое запрошенное поле, пустое — как `null` или `[]`). Модалка
    при этом показывается целиком, помечаются только такие поля (решение пользователя). «Yet» может
    длиться долго: документ с упавшим детальным запросом инкрементальный обход (по
    `date_last_updated`) перескачает, только когда ComicVine обновит объект снова, или его перекачает
    полный обход.
- **Документ, скачанный только списком** (`crawl_source: "list"`), — над телом модалки предупреждение
  «Only list data downloaded so far, details are not crawled yet». Такой документ появляется в начале
  каждого обхода: паук сначала пишет данные из списка и только потом делает детальный запрос; если
  детальный запрос упал, документ остаётся списочным до следующего обхода. Задачи поиска пропущенных
  выпусков по `crawl_source` не фильтруют, поэтому такой выпуск может попасть в таблицу, а модалку
  могут открыть в любой момент. В списочных документах нет `description` (у всех трёх уровней), у
  выпусков — ещё `person_credits`, `store_date` и `associated_images` (поля списочных запросов —
  `read_comics/spiders/spiders/*_spider.py`, `LIST_URL_PATTERN`). Правило «ключа нет — not downloaded
  yet» покрывает их без отдельного перечня полей. *(моё решение)*
- **Описания** (`description`) — HTML из ComicVine. Обрабатываются так же, как на детальных страницах
  сайта (см. «Описания»).

### Издатель

Данные — документ `comicvine_publishers` с `id = publisher_comicvine_id`.

- **Шапка:** `name`.
- **Алиасы** — все, без сокращения «… ещё N» (решение пользователя), списком, каждый алиас отдельным
  пунктом; список в несколько колонок. Списком, а не через запятую: в самих алиасах бывают запятые.
- **Короткое описание** — `deck`.
- **Описание** — `description`.

### Том

Данные — документ `comicvine_volumes` с `id = volume_comicvine_id` и документы `comicvine_issues` с
`volume.id` этого тома.

- **Шапка:** `name (start_year)`.
- **Строка метаданных:** год (`start_year`); издатель (`publisher.name`); «Issues in ComicVine dump» —
  число документов `comicvine_issues` с этим `volume.id` (подпись именно «in ComicVine dump» (решение пользователя): это число выпусков в нашей копии данных ComicVine, а не скачанных в основную базу и S3; копия может отставать от ComicVine); номера первого и последнего выпуска (`first_issue.issue_number`,
  `last_issue.issue_number` — значения ComicVine). Число выпусков и первый/последний — предложены
  мной, приняты пользователем.
- **Алиасы** — как у издателя.
- **Короткое описание** — `deck`. **Описание** — `description`.
- **Сетка обложек всех выпусков тома из нашей базы:**
  - картинка — `image.small_url` (~412×640, 110–150 КБ) — вариант «B», выбран пользователем из двух
    показанных (`thumb_url` против `small_url`);
  - **размер задаётся шириной: 150px при любой ширине окна, высота — по пропорциям картинки**
    (решение пользователя: у части обложек пропорция нестандартная, и при фиксированной высоте они
    выходят шире или уже соседних). Плитки переносятся на новые строки. Само число 150px — *моё
    решение*: это готовый класс темы `.width-150`, и он ближе всего к утверждённому варианту «B»
    (там была высота 240px, при типичной пропорции 412×640 это ~155px ширины);
  - под картинкой — `#issue_number` и `cover_date`;
  - картинки грузятся лениво (`loading="lazy"`) — обязательно, см. «Анти-цели». У `img` — атрибуты
    `width="412" height="640"` (типичная пропорция `small_url`) и классы `.width-150.h-auto`.
    Атрибуты нужны как заглушка: под ещё не загруженную картинку браузер резервирует место по их
    пропорции, а после загрузки высота пересчитывается по настоящей пропорции картинки. Без них
    незагруженная картинка имеет нулевую высоту, все плитки сразу попадают в видимую область, и
    ленивая загрузка тянет их разом;
  - клик по обложке открывает `image.original_url` в новой вкладке *(моё решение: вложенные модалки
    Bootstrap 4 толком не поддерживает)*;
  - **порядок** — как в таблице: по `numerical_number` (`"½"` → 0.5, числовой префикс номера →
    число, номер без числового префикса → 0, пустой номер — в конец, как `NULLS LAST` в Postgres),
    затем по `issue_number`, затем по `id`. Так обложки идут в том же порядке, что строки таблицы.
    Правило `numerical_number` берётся из общего хелпера (см. «Общие хелперы в `read_comics/utils`»).

### Выпуск

Данные — документ `comicvine_issues` с `id = comicvine_id`.

- **Шапка:** `<volume.name> #<issue_number>`.
- **Слева — основная обложка:** `image.medium_url` (~618×960), **ширина 300px, высота по пропорциям**;
  клик открывает `image.original_url` в новой вкладке. *(300px — моё решение: готовый класс темы
  `.width-300`; при типичной пропорции это ~470px высоты)*
- **Справа:**
  - cover date и store date (`cover_date`, `store_date`) — предложены мной, приняты пользователем;
  - название (`name`);
  - короткое описание (`deck`);
  - описание (`description`);
  - **авторы** — все `person_credits` в виде «имя — роль», списком в несколько колонок (предложено
    мной, принято пользователем).
- **Ниже — варианты обложек** (`associated_images`): заголовок с их числом; картинки —
  `original_url`, **ширина 150px, высота по пропорциям**, лениво; клик открывает оригинал в новой
  вкладке. Других размеров у вариантов нет: ComicVine хранит для них только оригинал (`scale_small` и
  т. п. по тому же пути отдают 404, проверено 2026-10-22), поэтому они тяжёлые — ~0.5–1 МБ каждая, у
  The Amazing Spider-Man (2022) #1 их 16, это ~10 МБ. Нет вариантов — «none». Атрибуты
  `width`/`height` — заглушка с той же типичной пропорцией 412×640, что у сетки тома, по той же
  причине (настоящие размеры вариантов заранее неизвестны).
- **Алиасы на уровне выпуска не показываем** *(моё решение)*: в базе они фактически не заполнены (3
  документа из ~1,1 млн, и везде мусорное `"0.00"`).

## Описания

Обработка `description` повторяет детальные страницы сайта и берётся из общего хелпера (см.
«Общие хелперы в `read_comics/utils`»):

- издатель и том — убрать `<a>`, оставив текст ссылки (сейчас — `ComicvineSyncModel.strip_links`);
- выпуск — то же плюс вырезать таблицу «List of covers and their creators» (сейчас —
  `Issue.get_description`);
- затем у ленивых картинок (`img.js-lazy-load-image`) взять `src` из `data-src` (сейчас — часть
  свойства `ComicvineSyncModel.description`). Класс `image-full-size` не добавляем: модалки
  полноразмерной картинки на этой странице нет.

Ссылки убираются, потому что ведут на тот же лежащий сайт. Картинки и `<figure>` внутри описаний
оставляем, как на детальных страницах. Выводится через `|safe`, как на детальных страницах; HTML
приходит из ComicVine без нашей санитизации — **принятый риск**: страница доступна только staff.
*(моё решение)*

Алиасы приходят одной строкой, по алиасу на строку; разделитель `\n` или `\r\n` (`\r\n` — примерно у
10% документов с алиасами), разбивать с учётом обоих, пустые строки отбрасывать.

## Общие хелперы в `read_comics/utils`

Логика, которая сейчас живёт в методах моделей, выносится в функции пакета `read_comics/utils` —
без зависимостей от моделей, на вход строка, на выход строка или число (решение пользователя).
Модалка вызывает эти функции, а существующие методы моделей становятся тонкими обёртками над ними,
и их поведение не меняется:

- **Обработка описаний** — три шага из раздела «Описания»: убрать ссылки, вырезать таблицу обложек
  выпуска, подставить `src` ленивым картинкам. На хелперы переходят `ComicvineSyncModel.strip_links`
  (`utils/models.py:265`; остаётся методом, потому что `FIELD_MAPPING` вызывает его по имени через
  `getattr`), `Issue.get_description` (`issues/models.py:188`, по той же причине) и свойство
  `ComicvineSyncModel.description` (`utils/models.py:555`, шаг с `data-src`; добавление
  `image-full-size` остаётся в свойстве).
- **`numerical_number` из номера выпуска** — `"½"` → 0.5, числовой префикс → число, без числового
  префикса → 0, пустой номер → `None`. На хелпер переходят `MissingIssue.set_numerical_number`
  (`missing_issues/models.py:85`) и `Issue.set_numerical_number` (`issues/models.py:254`) — там тот
  же код слово в слово *(второе — моё решение: вынести и оставить копию значило бы оставить
  дублирование)*.

## Серверная часть

- **Адрес фиксирован** (решение пользователя): `/missing_issues/comicvine/<level>/<int:comicvine_id>/`.
  В `read_comics/missing_issues/urls.py` это
  `path("comicvine/<str:level>/<int:comicvine_id>/", ..., name="comicvine_details")` *(имя маршрута —
  моё решение)*. `level` — `publisher`, `volume` или `issue`; любое другое значение — 404. Маршрут
  объявляется до маршрутов категорий (`<str:category>/<str:slug>/...`): по числу сегментов они с ним
  сейчас не пересекаются, порядок страхует на будущее.
- **Ключ — id объекта своего уровня:** `publisher_comicvine_id`, `volume_comicvine_id` или
  `comicvine_id` выпуска. Это отличается от Skip/Ignore, которые на всех уровнях принимают id выпуска.
- `GET`, закрыт `IsAdminMixin`, отдаёт **HTML-фрагмент** — всё содержимое `.modal-content` (шапка,
  тело, подвал с ссылкой на ComicVine и датой), отрисованный Django-шаблоном на уровень. *(моё
  решение: страница и так подменяет HTML таблицы фрагментами по AJAX, и фрагмент проще, чем отрисовка
  JSON на клиенте)*
- **Документа нет в Mongo** (паук ещё не скачал) — фрагмент с текстом «No data for this object in our
  database yet», HTTP 200, чтобы JS показал его как обычное содержимое.
- **Только Mongo**: в Postgres эндпоинт не ходит.
- **Запросы к Mongo** — узкие проекции (только поля, которые выводятся). Обложки тома — по `volume.id`
  (индекс есть); сортировка — в Python по правилу из раздела «Том».
- Имена коллекций Mongo — атрибутами класса вьюхи (как у задач), чтобы тесты могли подставить
  тестовые коллекции.

## Поведение на странице

- Одна модалка на страницу, объявлена в `{% block modals %}` шаблона `missing_issues_list.html`
  (этот шаблон переопределяет блок без `{{ block.super }}` — добавлять туда же, рядом с
  `#doReloadModal`).
- Обработчик клика привязывается **так же, как у Skip/Ignore** (решение пользователя): `#table-wrapper`
  после Skip/Ignore перерисовывается, и в `missing_issues.js` для этого уже есть схема — функции
  привязки (`initButtons()`, `initCopy()`) вызываются при загрузке страницы и повторно в обработчике
  успешного ответа Skip/Ignore после вставки новой таблицы. Новая функция привязки вызывается в тех же
  двух местах. У кнопки модалки нет классов `.btn-skip`/`.btn-ignore`: `initButtons()` блокирует
  кнопки с этими классами на время запроса.
- По клику: модалка открывается сразу, старое содержимое удаляется, в теле — индикатор загрузки;

## Тесты

- **Эндпоинт** (pytest, Django test client): для каждого уровня — фрагмент содержит ключевые поля из
  документа; не-staff — 403; документа нет — текст «No data for this object in our database yet» и 200;
  алиасы с `\r\n` разбиваются; у тома — порядок обложек по правилу таблицы (включая пустой номер в
  конце); у картинок сетки и вариантов — `loading="lazy"` и атрибуты `width`/`height`; документ с
  `crawl_source: "list"` — предупреждение и «not downloaded yet» у полей без ключа, при этом пустое
  поле с ключом — «none»; неизвестный `level` — 404.
- **Хелперы в `read_comics/utils`** — юнит-тесты без базы: `numerical_number` (`"½"`, `"12"`,
  `"12.5"`, `"1A"`, `"A"`, `""`, `None`); обработка описаний (ссылки убраны с сохранением текста,
  таблица обложек выпуска вырезана, `src` у ленивых картинок подставлен из `data-src`). Существующие
  тесты, затрагивающие методы моделей (например `missing_issues/tests/test_write_plan.py`,
  пересчёт `numerical_number`), проходят без изменений.
- **Попутные баги:** на странице категории у кнопки Ignore издателя адрес `category_ignore_publisher`;
  в `field_list` списочного запроса `IssuesSpider` есть отдельные поля `associated_images` и
  `store_date`.
- Mongo в тестах — тестовые коллекции через атрибуты класса (как в
  `read_comics/missing_issues/tests/conftest.py`).
- Шаг тестов в CI заканчивается на `|| true` и падения не ловит — прогнать тесты локально.

## Приёмка

- Тесты выше проходят локально.
- **Визуально, поэкранно:** скриншоты трёх модалок (издатель, том, выпуск) сверены с разделом
  «Экраны» этой спеки. Только светлая тема: `dark-layout.css` в `base.html` подключён, но тёмная тема
  на сайте не включается — у `<body>` нет класса `dark-layout`, переключателя нет. *(моё решение)*
- На большом томе (например, Detective Comics 1937, 883 выпуска в базе) модалка открывается без
  подвисания страницы и обложки догружаются по мере прокрутки.
- Обложка с нестандартной пропорцией не искажена: ширина как у соседних, высота по её собственной
  пропорции.
- После Skip/Ignore (таблица перерисована по AJAX) кнопки открытия модалки работают.
- На странице категории «Ignore» издателя игнорирует издателя, а не пропускает его.
- Описание на любой детальной странице (например, тома) выглядит как раньше: правила
  `.detail-full-description` переехали в `common.css`, а не пропали.

## Чьи решения

Решения пользователя: состав данных по уровням; принятые предложения (число выпусков тома и
первый/последний, даты выпуска, авторы с ролями); отказ от сюжетных арок, от списка томов издателя и
от подсветки пропущенных выпусков в сетке обложек; все алиасы без сокращения; модалка на весь экран;
сетка обложек — `small_url`; размер картинок задаётся шириной, высота по пропорциям; картинки по
ссылкам ComicVine; минимальная вёрстка; оба попутных бага (Ignore издателя и запятая в
`issues_spider.py`) — в этой задаче; `full_spider.py` не трогаем; адрес эндпоинта
`/missing_issues/comicvine/<level>/<int:comicvine_id>/`; привязка обработчика клика — по схеме
Skip/Ignore; порядок выбора классов «готовый → готовый с доработкой → свой CSS»; обработка описаний и
`numerical_number` — общими хелперами в `read_comics/utils`.

Мои решения (проверить при чтении):

1. Ширины — готовыми классами темы: сетка тома и варианты — 150px (`.width-150`), основная обложка
   выпуска (`medium_url`) — 300px (`.width-300`); варианты — оригиналы.
2. Клик по любой обложке — картинка в новой вкладке, без вложенной модалки.
3. Ссылки в описаниях убираются; картинки внутри описаний остаются; HTML выводится через `|safe`.
4. Алиасы на уровне выпуска не показываются.
5. Пустые поля показываются с «none», поля без ключа в документе — с «not downloaded yet», у
   списочного документа — предупреждение; ничего не прячется.
6. Кнопка — рядом с существующей ссылкой; без id уровня кнопки нет.
7. Эндпоинт отдаёт HTML-фрагмент; при отсутствии документа — 200 и текст.
8. Порядок обложек — как у строк таблицы.
9. В подвале модалки — дата, на которую данные скачаны в нашу базу.
10. Тексты интерфейса — по-английски, как вся страница.
11. Визуальная приёмка — только в светлой теме.
12. Имя маршрута — `comicvine_details`.
13. `Issue.set_numerical_number` тоже переходит на общий хелпер (в нём тот же код).
14. Списки алиасов и авторов — `ul.card-columns` (готовый класс не по прямому назначению) вместо
    своего правила `columns`.
15. Правила `.detail-full-description` переезжают из `detail.css` в `common.css`, а не копируются.
