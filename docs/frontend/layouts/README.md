# Layouts

Page layout wrappers.

## Documentation

- [default.md](default.md) — Dashboard layout with sidebar
- [blank.md](blank.md) — Minimal layout for auth pages

## Overview

Layouts wrap page content and provide consistent structure. Set via `definePageMeta({ layout: 'name' })`.

| Layout | Use Case |
|--------|----------|
| `default` | Main application pages with sidebar navigation |
| `blank` | Auth pages (login, register) without navigation |
