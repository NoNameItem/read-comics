# Components

Reusable Vue components.

## Documentation

- [UserMenu.md](UserMenu.md) — User dropdown menu in sidebar footer
- [PageWithHeader.md](PageWithHeader.md) — Dashboard panel with navbar and breadcrumbs
- [NotificationsSlideover.md](NotificationsSlideover.md) — Notifications panel (placeholder)

## Overview

Components are auto-imported by Nuxt and can be used directly in templates without explicit imports.
