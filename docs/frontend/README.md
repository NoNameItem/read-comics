# Frontend (Nuxt 3)

The client is built with Nuxt 3 and runs independently from Django.

## Structure
- `frontend/pages/` — routes and pages.
- `frontend/components/` — components.
- `frontend/stores/` — Pinia stores.
- `frontend/assets/` — assets.
